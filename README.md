# Photon Landing System

Reusable landing page starter kit built with React, TypeScript, Redux Toolkit, MUI, theme context, language context, and user context.

## Stack

- React 19
- TypeScript
- Redux Toolkit
- MUI
- react-i18next
- React Router
- Vite

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
